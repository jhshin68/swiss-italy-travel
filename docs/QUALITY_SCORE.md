# QUALITY_SCORE.md — 코드 품질 기준

> 에이전트가 생성한 코드의 품질을 측정하는 기준.
> PR 머지 전 이 체크리스트를 통과해야 한다.

## 1. 자동 검증 (CI에서 실행)

| 검사 | 도구 | 통과 기준 |
|------|------|-----------|
| 타입 체크 | `tsc --noEmit` | 에러 0 |
| 린트 | ESLint | 에러 0, 경고 5개 이하 |
| 포맷팅 | Prettier | 차이 0 |
| 빌드 | `next build` | 성공 |
| 테스트 | Vitest | 전체 통과 |

## 2. 코드 리뷰 체크리스트

### 구조
```
□ 파일 300줄 이하
□ 함수 50줄 이하
□ 중첩 3단계 이하 (if/for)
□ 단일 책임 원칙 (한 파일 = 한 역할)
□ 순환 의존성 없음
```

### 타입 안전성
```
□ any 사용 없음 (불가피 시 주석 사유 명시)
□ as 타입 단언 최소화
□ API 응답 타입 정의됨
□ Props interface 정의됨
□ null/undefined 안전 처리
```

### 에러 처리
```
□ try-catch 적절히 사용
□ 사용자 친화적 에러 메시지 (한국어)
□ 에러 시 앱 전체가 죽지 않음 (Error Boundary)
□ 네트워크 에러 → 오프라인 fallback
□ 빈 상태 UI 있음
```

### 접근성
```
□ 터치 타겟 44px 이상
□ alt 텍스트 / aria-label
□ 색상 대비 4.5:1 이상
□ 키보드 네비게이션 가능
```

### 성능
```
□ 불필요한 리렌더링 없음
□ 이미지 최적화 (next/image)
□ 무거운 컴포넌트 dynamic import
□ 메모이제이션 적절 사용 (과도 X)
```
