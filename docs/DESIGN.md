# DESIGN.md — UI/UX 디자인 가이드

> 이 문서는 에이전트가 화면을 만들 때의 시각적·구조적 기준이다.
> 모든 컴포넌트, 페이지, 인터랙션은 이 문서의 원칙을 따른다.

## 1. 디자인 철학

### 핵심 키워드
```
따뜻함 · 감성 · 여행의 설렘 · 가족의 안심
```

### 디자인 원칙 (우선순위순)

| 순위 | 원칙 | 의미 | 예시 |
|------|------|------|------|
| 1 | **한눈에 (Glanceable)** | 열자마자 오늘 할 일이 보인다 | 대시보드 = 오늘 일정 카드 |
| 2 | **엄마도 쓸 수 있게 (Accessible)** | IT 비전문자도 헤매지 않는다 | 아이콘 + 텍스트 병기, 큰 터치 영역 |
| 3 | **여행 감성 (Wanderlust)** | 앱을 열면 여행 기분이 난다 | 따뜻한 색감, 여행지 사진 배경, 부드러운 모션 |
| 4 | **오프라인에서도 당당히 (Offline-aware)** | 오프라인 상태가 자연스럽다 | 오프라인 배지 (경고가 아닌 안내), 캐시 데이터 표시 |

## 2. 컬러 시스템

### 메인 팔레트

```
Primary:     #E8725A  (테라코타 — 이탈리아 지붕, 따뜻함)
Secondary:   #2D7D9A  (알프스 호수 블루 — 스위스, 신뢰감)
Accent:      #F4A84F  (석양 골드 — 강조, 알림)
Success:     #5BAD6F  (알프스 초원 그린 — 완료, 긍정)
Warning:     #E8A838  (치즈 옐로우 — 주의)
Error:       #D94848  (진한 레드 — 오류, 긴급)

Background:  #FFF9F5  (크림 화이트 — 따뜻한 베이스)
Surface:     #FFFFFF  (카드/모달 배경)
Text:        #2C2C2C  (본문 — 순수 블랙 피함)
Text-sub:    #7A7A7A  (보조 텍스트)
Border:      #E8E2DC  (따뜻한 그레이 테두리)
```

### 컬러 사용 규칙
```
- Primary(테라코타):  CTA 버튼, 선택된 탭, 핵심 강조
- Secondary(호수블루): 링크, 보조 버튼, 지도 UI 요소
- Accent(석양골드):   배지, 알림 카운트, 오늘 날짜 강조
- Background(크림):   전체 배경 — 순백 대신 따뜻함
- 카드:               Surface(흰색) + 미세 그림자 + 둥근 모서리(12px)
```

## 3. 타이포그래피

| 용도 | 폰트 | 사이즈 | 무게 |
|------|------|--------|------|
| 앱 제목 / 페이지 제목 | Pretendard | 24px | Bold (700) |
| 섹션 제목 | Pretendard | 18px | SemiBold (600) |
| 카드 제목 | Pretendard | 16px | SemiBold (600) |
| 본문 | Pretendard | 14px | Regular (400) |
| 보조 텍스트 / 캡션 | Pretendard | 12px | Regular (400) |
| 숫자 (금액, 시간) | Pretendard | 14~20px | Medium (500) |

### 폰트 규칙
```
- 한국어: Pretendard (무료, 가독성 우수)
- 영문/숫자: Pretendard 동일 (혼용 깔끔)
- 행간: 1.5 (본문), 1.3 (제목)
- 금액 표시: 항상 통화 기호 + 천 단위 콤마 (예: ₩45,000 / CHF 32.50)
```

### 4.2 하단 탭 바 (5탭)

| 순서 | 아이콘 | 라벨 | 페이지 | 설명 |
|------|--------|------|--------|------|
| 1 | 🏠 | 홈 | `/` | 오늘 요약 대시보드 |
| 2 | 📅 | 일정 | `/itinerary` | 일별 타임라인 |
| 3 | 🗺️ | 지도 | `/map` | 지도 + 위치 공유 |
| 4 | 💰 | 경비 | `/expenses` | 지출 기록 + 정산 |
| 5 | ℹ️ | 정보 | `/info` | 비상연락처 + 여행팁 |

### 탭 바 디자인 규칙
```
- 높이: 56px (iOS 세이프 에리어 포함 시 +34px)
- 선택 상태: Primary 컬러(테라코타) + 아이콘 채움
- 비선택: Text-sub(#7A7A7A) + 아이콘 윤곽선
- 터치 영역: 최소 44x44px
- 배경: Surface(흰색) + 상단 1px 테두리(Border 컬러)
```

## 6. 컴포넌트 디자인 규칙

### 6.1 카드 (Card)
```css
background: #FFFFFF;
border-radius: 12px;
box-shadow: 0 2px 8px rgba(0, 0, 0, 0.06);
padding: 16px;
margin-bottom: 12px;
```

### 6.2 버튼 (Button)
| 종류 | 배경 | 텍스트 | 용도 |
|------|------|--------|------|
| Primary | #E8725A | 흰색 | CTA (저장, 추가) |
| Secondary | 투명 + #2D7D9A 테두리 | #2D7D9A | 보조 액션 |
| Ghost | 투명 | #7A7A7A | 취소, 덜 중요한 액션 |
| Danger | #D94848 | 흰색 | 삭제 (confirm 후) |

```
공통: border-radius 8px, 높이 44px, 패딩 좌우 20px
터치 영역: 최소 44x44px (모바일 접근성)
```

### 6.3 입력 필드 (Input)
```css
border: 1px solid #E8E2DC;
border-radius: 8px;
padding: 12px 16px;
font-size: 16px;  /* iOS 확대 방지 */
background: #FFFFFF;
/* 포커스 시 */
border-color: #2D7D9A;
box-shadow: 0 0 0 3px rgba(45, 125, 154, 0.1);
```

### 6.4 상태 표시
```
오프라인:   상단 바에 "📡 오프라인 모드" 배너 (경고가 아닌 안내 톤)
           배경: #FFF3E0 (따뜻한 옐로우), 텍스트: #E8A838
           
로딩:      스켈레톤 UI (회색 박스 펄스 애니메이션)
           스피너 사용 최소화 — 체감 속도 향상

빈 상태:   일러스트 + 안내 문구 + CTA
           예: "아직 오늘 지출이 없어요 ✈️" + [첫 지출 기록하기]

에러:      인라인 에러 메시지 (빨간 텍스트 + 재시도 버튼)
           모달/팝업 최소화
```

## 7. 모션·애니메이션

```
원칙: 의미 있는 모션만. 장식용 애니메이션 금지.

페이지 전환:    없음 (탭 전환은 즉시)
카드 등장:      fade-in + 살짝 위로 (duration: 200ms, ease-out)
모달 열기:      slide-up from bottom (duration: 300ms)
버튼 클릭:      scale(0.97) → scale(1) (duration: 100ms)
스와이프:       일정 날짜 이동 시 좌우 슬라이드 (자연스러운 감속)
위치 마커:      부드러운 이동 (transition: 1s ease)
```

## 8. 반응형 규칙

```
이 앱은 모바일 퍼스트. 데스크톱은 보너스.

Mobile (기준):     ~430px   ← 주 사용 환경
Tablet:           431~768px ← 2열 레이아웃 허용
Desktop:          769px~    ← 사이드바 + 메인 2분할

모바일 우선 규칙:
  - 최소 터치 영역: 44x44px
  - 최소 폰트: 12px (접근성)
  - 입력 폰트: 16px (iOS 자동 줌 방지)
  - 하단 탭 바: 모바일 전용 (데스크톱은 사이드 내비)
  - Safe area: iOS 노치/하단 대응 (env(safe-area-inset-*))
```

## 9. 아이콘·이모지 전략

```
방식: 시스템 이모지 + Lucide Icons 혼합

이모지 사용처 (감성·친근함):
  - 카테고리 라벨: 🍽️식사 🚂교통 🏨숙소 🎫관광 🛍️쇼핑
  - 국기: 🇨🇭 🇮🇹 🇰🇷
  - 날씨: ☀️ ⛅ 🌧️ ❄️
  - 일정 타입: 📍장소 🍳식사 ⛰️활동

Lucide Icons 사용처 (UI 기능):
  - 네비게이션: Home, Calendar, Map, Wallet, Info
  - 액션: Plus, Edit, Trash, ChevronLeft, ChevronRight
  - 상태: Check, AlertCircle, Wifi, WifiOff
```

## 10. 접근성 (Accessibility)

```
필수 준수 사항:
  - 색상 대비: 4.5:1 이상 (WCAG AA)
  - 터치 타겟: 44x44px 이상
  - 이미지 alt 텍스트 필수
  - 포커스 링: 키보드 네비게이션 지원
  - 의미론적 HTML: <nav>, <main>, <article>, <button> 적절 사용
  - 폰트 최소 12px
  
개인용이지만 준수하는 이유:
  → 상용화 시 재작업 방지
  → 가족 중 시력 약한 멤버 배려
```
