# PS-005: PIN 인증 + 멤버 선택

> 가족 4인이 각자 디바이스에서 3초 만에 로그인한다.

## 사용자 스토리

```
AS 가족 멤버
I WANT 복잡한 로그인 없이 바로 앱에 들어가고 싶다
SO THAT 여행 중 번거로움이 없다
```

## 인증 플로우

```
[최초 접속]
1. PIN 4자리 입력
2. 서버 검증 → 성공 시 멤버 선택 화면
3. 멤버 선택
4. JWT 발급 → httpOnly cookie 저장
5. 디바이스 토큰 발급 → localStorage
6. 대시보드로 이동

[재접속]
1. 디바이스 토큰 확인
2. 유효 → 자동 로그인 → 대시보드
3. 만료 → PIN 재입력

[멤버 전환]
1. 프로필 아이콘 탭
2. "멤버 전환" 선택
3. 멤버 선택 화면 (PIN 재입력 불필요)
```

## 데이터 요구사항

```typescript
interface Member {
  id: string;
  tripId: string;
  name: string;              // "진형", "지현", "동우", "유진"
  emoji: string;             // "👨", "👩", "👦", "👧"
  color: string;             // 멤버 구분 컬러 (지도 마커 등)
  role: 'admin' | 'member';  // admin = 일정 수정 권한
  createdAt: DateTime;
}

// 서버 측
interface TripAuth {
  tripId: string;
  pinHash: string;           // bcrypt 해시
  jwtSecret: string;
}
```

## 보안 로직

```
PIN 저장: bcrypt 해시 (서버)
JWT 만료: 30일 (여행 기간 커버)
Rate limiting: 5회 연속 실패 → 5분 잠금
디바이스 토큰: UUID v4, localStorage 저장
CORS: swiss-italy-travel.vercel.app만 허용
```

## 엣지 케이스

| 케이스 | 처리 |
|--------|------|
| PIN 5회 실패 | "5분 후 다시 시도해주세요" + 잠금 |
| 디바이스 분실 | 다른 디바이스에서 PIN 재입력으로 접근 |
| 쿠키 삭제 | PIN 재입력 |
| 2명이 같은 멤버 선택 | 허용 (같은 가족 — 제약 불필요) |
| 오프라인에서 최초 접속 | 불가 → "인터넷 연결 후 로그인해주세요" |
| 오프라인에서 재접속 | 디바이스 토큰으로 로컬 인증 허용 |

## 수용 기준

```
□ PIN 입력 → 대시보드까지 5초 이내
□ 재접속 시 자동 로그인 (1초 이내)
□ 5회 실패 시 5분 잠금 동작
□ 멤버 전환 PIN 재입력 없이 가능
□ 오프라인 재접속 시 로컬 인증 동작
```
