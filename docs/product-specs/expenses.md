# PS-003: 경비 기록 + 정산

> 여행 중 지출을 실시간으로 기록하고, 여행 후 "누가 누구에게 얼마"를 정산한다.

## 사용자 스토리

```
AS 결제한 멤버
I WANT 결제 직후 3탭 이내로 금액을 기록하고 싶다
SO THAT 나중에 기억 안 나는 일이 없다

AS 여행 총무 (진형)
I WANT 전체 지출 현황과 정산 결과를 한눈에 보고 싶다
SO THAT 예산 관리와 공정한 정산이 가능하다
```

### 지출 추가 모달
```
DESIGN.md 섹션 5.4 참조 (경비 입력 모달 와이어프레임)

핵심 필드:
  1. 금액 + 통화 (CHF/EUR/KRW) ← 필수
  2. 카테고리 (6종) ← 필수
  3. 설명 ← 필수
  4. 결제자 ← 필수 (기본: 현재 로그인 멤버)
  5. 분할 방식 ← 필수 (기본: 4인 균등)
  6. 날짜/시간 ← 자동 (현재 시각, 수정 가능)
  7. 영수증 사진 ← 선택 (P2로 미룸)
```

## 데이터 요구사항

### Expense 데이터 구조
```typescript
interface Expense {
  id: string;
  tripId: string;
  amount: number;           // 원래 통화 금액
  currency: 'CHF' | 'EUR' | 'KRW';
  amountKRW: number;        // KRW 환산액
  exchangeRate: number;     // 적용 환율
  category: 'meal' | 'transport' | 'attraction' | 
            'shopping' | 'accommodation' | 'other';
  description: string;
  paidById: string;         // 결제 멤버 ID
  date: string;             // "2026-10-05"
  time: string;             // "12:45"
  splits: ExpenseSplit[];
  receiptUrl?: string;      // P2
  syncStatus: 'synced' | 'pending';  // 오프라인 동기화 상태
  createdAt: DateTime;
  updatedAt: DateTime;
}

interface ExpenseSplit {
  memberId: string;
  amount: number;           // KRW 기준 분할 금액
}
```

## 비즈니스 로직

```
환율 적용:
  1. 당일 캐시된 환율 사용
  2. 환율 없으면 마지막 캐시 환율 + "⚠️ 추정 환율" 표시
  3. 온라인 복귀 시 정확한 환율로 재계산

분할 방식:
  - 균등: amount / memberCount (100원 단위 반올림)
  - 직접 입력: 멤버별 금액 지정 (합계 검증)
  - 제외: 특정 멤버 제외 가능 (나머지 균등)

정산 알고리즘:
  → DD-006 (adr-expense-settlement.md) 참조

카테고리 자동 추천 (P1):
  "택시" → 🚂교통 / "점심" → 🍽️식사 (키워드 기반)
```

## 엣지 케이스

| 케이스 | 처리 |
|--------|------|
| 0원 지출 | 입력 불가 (검증) |
| 동일 시각 중복 입력 | 허용 (같은 시간에 여러 건 가능) |
| 오프라인에서 여러 멤버가 동시 입력 | Last-Write-Wins, 각자 다른 Expense이므로 충돌 없음 |
| 통화 변경 | 환율 재계산 자동 반영 |
| 지출 삭제 | confirm 후 삭제, 정산 결과 자동 재계산 |
| 예산 초과 | 경고 배너 표시 (차단하지 않음) |
| 소수점 처리 | CHF/EUR: 소수점 2자리, KRW: 정수 |

## 오프라인 동작
```
✅ 지출 목록 열람: 캐싱된 데이터
✅ 지출 입력: IndexedDB 저장 (pending 상태)
✅ 정산 계산: 로컬 데이터로 계산 가능
⚠️ 환율: 마지막 캐시 환율 사용 + "추정" 표시
⚠️ 다른 멤버의 입력: 온라인 복귀 후 동기화
```

## 수용 기준

```
□ 지출 추가: 3탭 이내 (탭바 → + 버튼 → 저장)
□ 금액 입력 시 KRW 환산액 실시간 표시
□ 카테고리별/결제자별/일별 통계 표시
□ 정산 결과: 최소 거래 수로 "누가 누구에게 얼마" 표시
□ 정산 완료 체크 가능
□ 오프라인에서 지출 입력 + 목록 열람 정상 동작
□ 온라인 복귀 시 pending 데이터 자동 동기화
```
