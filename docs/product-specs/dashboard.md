# PS-001: 홈 대시보드

> 앱을 열면 가장 먼저 보이는 화면. "오늘 뭐 하지?"를 3초 안에 답한다.

## 사용자 스토리

```
AS 가족 멤버
I WANT 앱을 열자마자 오늘 할 일과 현재 상황을 한눈에 보고 싶다
SO THAT 카톡/PDF를 뒤지지 않아도 된다
```

## 화면 구성

### 상단 헤더
```
🇨🇭 Day 3 · 10월 5일 (일) · 루체른
맑음 15°C                          [👤]
```
- 국기: 현재 국가 자동 표시 (스위스 🇨🇭 / 이탈리아 🇮🇹)
- D-Day: 여행 시작일 기준 Day N
- 날짜: 요일 포함
- 도시: 당일 일정의 첫 장소 기준 도시명
- 날씨: 캐싱된 날씨 정보 (없으면 숨김)
- 프로필: 현재 로그인 멤버 아바타

### 오늘의 일정 카드
```
📍 오늘의 일정
━━━━━━━━━━━━━━━━━━━━━
09:00  🍳 호텔 조식
10:00  📍 카펠교 → 빈사의 사자상    ← 현재 시간 기준 강조
12:30  🍽️ Old Swiss House
14:00  ⛰️ 필라투스 산 등반
       +2개 더보기 →
```
- 최대 5개 표시, 나머지는 "더보기" → 일정 탭으로 이동
- 현재 시간 기준 진행 중인 일정은 Primary 컬러 좌측 바 + 볼드
- 지난 일정은 텍스트 회색 처리
- 각 항목 탭 → 일정 상세 화면으로 이동

### 요약 카드 (2열)
```
┌─────────────┐ ┌─────────────┐
│ 💰 오늘 지출  │ │ 👨‍👩‍👧‍👦 가족 위치  │
│ ₩125,400    │ │ 모두 함께 📍 │
│ 예산 대비 62% │ │ (또는 위치 목록)│
└─────────────┘ └─────────────┘
```
- 오늘 지출: 당일 총 지출액 (KRW 환산), 탭 → 경비 탭
- 가족 위치: 실시간 위치 요약 (P1 — 미구현 시 숨김)

### 비상 정보 카드
```
🚨 비상 정보
숙소: Hotel Schweizerhof ☎️ +41-xxx
긴급: 112 (유럽 공통)
[전체 보기 →]
```
- 항상 표시 (숨길 수 없음)
- 당일 숙소 + 긴급 번호
- "전체 보기" → 정보 탭

## 데이터 요구사항

| 데이터 | 소스 | 갱신 주기 |
|--------|------|-----------|
| 오늘 일정 | DayPlan + Spot | 앱 열 때 |
| 오늘 지출 합계 | Expense (당일 필터) | 실시간 |
| 숙소 정보 | InfoCard (당일 숙소) | 일 1회 |
| 날씨 | 외부 API 캐시 | 일 1회 |
| D-Day | Trip.startDate 기준 계산 | 계산 |

## 비즈니스 로직

```
D-Day 계산:
  dayNumber = diff(today, trip.startDate) + 1
  
현재 일정 강조:
  currentSpot = spots.find(s => s.startTime <= now && s.endTime > now)
  nextSpot = spots.find(s => s.startTime > now) // 없으면 null

국가 판별:
  날짜 기반으로 일정에서 국가 추출 (DayPlan.country 필드)
  
날씨 대안 표시:
  해당 일정에 weatherAlternative가 있으면 ⚠️ 아이콘 표시
```

## 엣지 케이스

| 케이스 | 처리 |
|--------|------|
| 여행 시작 전 (D-Day 이전) | "여행까지 D-7" 카운트다운 표시 |
| 여행 종료 후 | 마지막 날 일정 표시 + "여행 완료 🎉" 배너 |
| 당일 일정 없음 | "자유 시간이에요 ✈️" 안내 |
| 오프라인 | 캐싱된 데이터 표시, 날씨 숨김 |
| 경비 0원 | "아직 오늘 지출이 없어요" |

## 오프라인 동작
```
✅ 일정 표시: 캐싱된 DayPlan으로 정상 동작
✅ 경비 합계: IndexedDB 로컬 데이터로 계산
✅ 비상 정보: 캐싱 필수 (앱 설치 시)
❌ 날씨: 숨김 처리
❌ 가족 위치: "오프라인" 표시
```

## 수용 기준 (Definition of Done)

```
□ 앱 열면 3초 이내에 오늘 일정 표시
□ 현재 시간 기준 진행 중 일정 강조
□ 오늘 지출 합계가 경비 탭 데이터와 일치
□ 비상 정보 카드 항상 표시
□ 오프라인에서 일정 + 비상 정보 정상 표시
□ 모바일(375px)에서 스크롤 없이 핵심 정보 확인 가능
```
