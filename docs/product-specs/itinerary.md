# PS-002: 일정 관리 (Itinerary)

> 12일간의 여행 일정을 일별 타임라인으로 보여주고 관리한다.

## 사용자 스토리

```
AS 가족 멤버
I WANT 오늘과 내일 일정을 시간순으로 보고 싶다
SO THAT "다음에 뭐 하지?"를 즉시 알 수 있다

AS 여행 총무 (진형)
I WANT 일정을 현장에서 수정할 수 있다
SO THAT 날씨/상황에 따라 유연하게 대응할 수 있다
```

## 데이터 요구사항

### Spot (장소) 데이터 구조
```typescript
interface Spot {
  id: string;
  dayPlanId: string;
  name: string;
  nameLocal?: string;        // 현지어 이름
  category: 'sightseeing' | 'meal' | 'hotel' |
            'transport' | 'shopping' | 'other';
  startTime: string;         // "14:00"
  endTime?: string;          // "18:00"
  address?: string;
  lat?: number;
  lng?: number;
  cost?: number;
  currency?: 'CHF' | 'EUR' | 'KRW';
  bookingRef?: string;       // 예약 번호
  notes?: string;
  weatherAlternative?: string;  // 날씨 대안
  imageUrl?: string;
  sortOrder: number;         // 타임라인 순서
}
```

### 초기 데이터
```
itinerary.ts (108개 장소)를 DB 시딩 시 DayPlan + Spot으로 변환.
날씨 대안이 있는 항목은 weatherAlternative 필드에 저장.
```

## 비즈니스 로직

```
타임라인 정렬: startTime 오름차순
이동 시간 표시: 연속된 Spot 사이 이동 수단 + 시간
  → 데이터에 있으면 표시, 없으면 숨김
현재 진행 중 판별: startTime <= now < endTime
날씨 대안: weatherAlternative 필드가 있으면 ⚠️ 아이콘 + 토글 표시
```

## 엣지 케이스

| 케이스 | 처리 |
|--------|------|
| 일정 없는 날 (자유일) | "자유 시간이에요! 🗺️ 주변 탐색해보세요" |
| 시간 미정 장소 | 시간 없이 "시간 미정" 라벨로 하단 표시 |
| 장소 삭제 | confirm 후 삭제, Undo 5초 제공 |
| 일정 겹침 | 겹치는 시간 빨간 경고 표시 |
| 날짜 변경선 (시간대) | 10월 말 서머타임 종료 → 자동 처리 |

## 오프라인 동작
```
✅ 전체 12일 일정 열람: 캐싱 필수
✅ 일정 수정: IndexedDB 저장 → 온라인 복귀 시 동기화
✅ 일정 추가: 로컬 저장 후 동기화
⚠️ 이미지: 캐싱된 것만 표시, 나머지 placeholder
```
