## 스펙 작성 규칙

```
모든 스펙은 다음 구조를 따른다:
1. 한 줄 요약
2. 사용자 스토리 (누가, 왜, 무엇을)
3. 화면 구성 (와이어프레임 또는 설명)
4. 데이터 요구사항 (입력/출력/저장)
5. 비즈니스 로직
6. 엣지 케이스
7. 오프라인 동작
8. 수용 기준 (Done의 정의)
```
