## 데이터 요구사항

### InfoCard 데이터 구조
```typescript
interface InfoCard {
  id: string;
  tripId: string;
  category: 'emergency' | 'accommodation' | 'insurance' | 
            'transport' | 'tips' | 'exchange' | 'checklist';
  title: string;
  content: string;          // Markdown 지원
  phoneNumbers?: PhoneEntry[];
  validFrom?: string;       // 특정 날짜부터 유효 (숙소)
  validTo?: string;         // 특정 날짜까지 유효
  sortOrder: number;
  isPinned: boolean;        // 긴급 연락처는 항상 고정
}

interface PhoneEntry {
  label: string;            // "프론트 데스크"
  number: string;           // "+41-41-410-0410"
}
```

### 초기 데이터
```
bookings.json (13건 예약) → accommodation, transport 카드로 변환
checklist.json → checklist 카드로 변환
긴급 연락처 → 수동 시딩 (대사관, 보험 등)
```

## 비즈니스 로직

```
숙소 자동 전환:
  날짜 기반으로 validFrom/validTo에 해당하는 숙소를 "오늘 숙소"로 표시
  
전화 걸기:
  전화번호 탭 → tel: 링크로 바로 전화 연결
  
긴급 연락처 고정:
  isPinned = true인 카드는 항상 최상단
  스크롤해도 접히지 않음 (Sticky 또는 항상 표시)
```

## 엣지 케이스

| 케이스 | 처리 |
|--------|------|
| 숙소 없는 날 (이동일) | "이동일 — 숙소 정보 없음" 표시 |
| 국가 전환일 | 스위스 → 이탈리아 긴급번호 자동 전환 |
| 전화번호 형식 | 국제전화 형식 통일 (+국가코드-지역-번호) |

## 오프라인 동작
```
✅ 모든 정보 카드: 앱 설치 시 전체 캐싱 (필수)
✅ 전화 걸기: 셀룰러 네트워크 사용 (데이터와 무관)
✅ 체크리스트 체크 상태: IndexedDB 저장
⚠️ 환율: 마지막 캐시 사용
```

## 수용 기준

```
□ 긴급 연락처 3초 이내 접근 (탭바 → 정보 → 최상단)
□ 오늘 숙소 자동 표시 (날짜 기반)
□ 전화번호 탭 → 바로 전화 연결
□ 100% 오프라인 동작 (환율 제외)
□ 국가별 긴급번호 자동 전환
□ 예약 번호 탭 → 클립보드 복사
```
