# PRODUCT_SENSE.md — 제품 비전·원칙·페르소나

> 이 문서는 모든 기능 결정의 최상위 기준이다.
> "이 기능을 넣을까 말까?" 판단이 필요할 때 이 문서로 돌아온다.

## 1. 제품 한 줄 정의

**가족이 해외여행 중 "지금 뭐 하지?", "얼마 썼지?", "너 어디야?"를 한 앱에서 해결하는 여행 컴패니언.**

## 2. 왜 만드는가 (Problem Statement)

### 해외 가족여행의 현실적 고통

| 고통 | 현재 해결 방식 | 문제점 |
|------|----------------|--------|
| 일정 확인 | 카톡에 공유된 PDF/엑셀 | 스크롤 지옥, 오프라인 불가, 수정 반영 안 됨 |
| "지금 어디야?" | 카톡으로 물어봄 | 로밍 끊기면 불통, 불안감 |
| 경비 정산 | 여행 끝나고 엑셀 정리 | 기억 안 남, 분쟁 소지, 귀찮아서 대충 |
| 현지 정보 | 구글·블로그 검색 | 매번 검색, 오프라인 불가, 정보 산재 |
| 비상 상황 | 머릿속 기억 | 대사관 번호? 보험 연락처? 급할 때 못 찾음 |

### 핵심 인사이트
```
"여행 중에는 인터넷이 불안정하다."
→ 오프라인 퍼스트 설계가 필수.

"가족 여행은 각자 따로 움직이는 시간이 있다."
→ 실시간 위치 공유가 안심을 준다.

"경비 정산은 여행의 마지막 숙제다."
→ 실시간으로 기록하면 여행 후 스트레스 제로.
```

## 3. 페르소나

### 여행 구성원 (4인)

| 멤버 | 관계 | 역할 | 비고 |
|------|------|------|------|
| 신진형 (진형) | 본인 | 여행 기획자 + 경비 관리자 + 앱 개발자 | IT 30년 경력, 앱 직접 기획 |
| 임지현 (지현) | 와이프 | 일정 동반 + 경비 공동 관리 | 스마트폰 일상 사용 수준 |
| 신동우 (동우) | 동생 | 일정 동반 | 스마트폰 일상 사용 수준 |
| 신유진 (유진) | 동우의 딸 (진형의 조카, 12세) | 일정 동반 | 키 150cm, 어린이 요금 적용 대상 |

### 주 사용자: 신진형 (진형, 여행 총무)

| 항목 | 내용 |
|------|------|
| 역할 | 여행 기획자 + 경비 관리자 + 비상 대응 |
| IT 역량 | 높음 (30년 IT 경력, 앱 직접 기획) |
| 니즈 | 가족 위치 파악, 경비 투명 관리, 일정 변경 즉시 공유 |
| 불만 | "카톡으로 일정 공유하면 대화에 묻힘" |
| 기대 | "내가 만든 앱으로 가족이 편하게 여행하는 것" |

### 보조 사용자: 임지현·신동우·신유진 (3인)

| 항목 | 내용 |
|------|------|
| IT 역량 | 중간 (스마트폰 일상 사용 수준) |
| 니즈 | 오늘 일정 한눈에 보기, 내 지출 확인, 일행 위치 확인 |
| 불만 | "앱이 복잡하면 안 씀" |
| 기대 | "열면 바로 오늘 할 것이 보이는 것" |

## 4. 핵심 가치 우선순위

```
1위: 단순함 (Simple)
    → 열면 오늘 일정이 바로 보인다
    → 3탭 이내로 모든 핵심 기능 접근
    → 가족 누구나 설명 없이 쓸 수 있다

2위: 오프라인 (Offline-first)
    → 일정·지도·비상정보는 인터넷 없이도 동작
    → 경비 입력은 오프라인 저장 → 온라인 복귀 시 동기화

3위: 안심 (Peace of mind)
    → 실시간 위치 공유로 "어디야?" 불안 해소
    → 비상 연락처·숙소 정보 즉시 접근
    → 경비 투명 관리로 여행 후 분쟁 제로

4위: 즐거움 (Delight)
    → 여행 사진·메모 기록
    → 일일 경비 리포트
    → 여행 후 추억 타임라인
```

## 5. 기능 우선순위 매트릭스

### P0 — 반드시 있어야 함 (MVP)
| 기능 | 설명 | 가치 연결 |
|------|------|-----------|
| 일정 뷰 | 일별 타임라인 + 장소 상세 | 단순함 |
| 오프라인 일정 | 캐싱된 일정 오프라인 열람 | 오프라인 |
| 경비 입력 | 금액·카테고리·결제자 기록 | 안심 |
| 경비 정산 | 누가 누구에게 얼마 보낼지 계산 | 안심 |
| 비상 정보 | 대사관·보험·숙소·긴급번호 | 안심 |
| 심플 인증 | 6자리 PIN 로그인 | 단순함 |

### P1 — 있으면 훨씬 좋음
| 기능 | 설명 | 가치 연결 |
|------|------|-----------|
| 실시간 위치 공유 | 가족 위치 지도에 표시 | 안심 |
| 지도 + 경로 | 오늘 방문 장소 지도 표시 + 도보 경로 | 단순함 |
| 오프라인 지도 | 사전 다운로드한 지역 지도 | 오프라인 |
| 환율 자동 계산 | CHF/EUR → KRW 실시간 변환 | 안심 |
| 날씨 정보 | 여행지 날씨 + 옷차림 추천 | 즐거움 |

### P2 — 상용화 때 추가
| 기능 | 설명 | 가치 연결 |
|------|------|-----------|
| 여행 사진 업로드 | 장소별 사진 첨부 | 즐거움 |
| 여행 리포트 | 여행 종료 후 자동 요약 리포트 | 즐거움 |
| 다중 여행 관리 | 여러 여행 생성·전환 | 확장성 |
| 소셜 로그인 | 구글/카카오 OAuth | 확장성 |
| 여행 템플릿 | 인기 여행지 일정 템플릿 | 확장성 |
| AI 추천 | 날씨·취향 기반 일정 제안 | 즐거움 |

## 6. 이 앱이 아닌 것 (Non-goals)

```
❌ 항공권·호텔 예약 플랫폼이 아니다
❌ 소셜 미디어 / 여행 블로그가 아니다
❌ 범용 지도 앱이 아니다 (구글맵 대체 X)
❌ 가계부 앱이 아니다 (여행 경비 한정)
❌ 여행사 B2B 솔루션이 아니다 (1차는 개인용)
```

## 8. 스위스·이탈리아 여행 컨텍스트

### 여행 기본 정보
| 항목 | 내용 |
|------|------|
| 기간 | 2026년 10월 (12일) |
| 인원 | 가족 4인 |
| 국가 | 스위스 → 이탈리아 |
| 통화 | CHF (스위스 프랑) + EUR (유로) + KRW (기준) |
| 시간대 | CEST (UTC+2) / CET (UTC+1) — 10월 말 서머타임 종료 주의 |

### 주요 이동 수단
```
- 스위스: 기차 (Swiss Travel Pass), 케이블카, 유람선
- 이탈리아: 기차 (Trenitalia/Italo)
- 국경 이동: 기차 (스위스 → 이탈리아)
```

### 앱에 사전 입력할 데이터
```
✅ 일정 (itinerary.ts — 108개 장소 항목, 날씨 대안 포함)
✅ 예약 (bookings.json — 13건 예약, 우선순위/비용 포함)  
✅ 체크리스트 (checklist.json — 짐싸기, 도전과제, 예산, 언어 가이드)
```
